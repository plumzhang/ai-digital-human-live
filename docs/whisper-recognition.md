# 本地语音识别

当前默认链路已迁移为 FunASR 中文 ASR，统一使用 POST /api/stt。见 [语音服务](speech-service.md)。

旧 Whisper 源码和模型目录保留用于历史兼容；麦克风、歌曲转录和RTC下行槽位确认均已使用 FunASR，不需要启动 Whisper。

组件槽位默认启用下行播报确认：OBS读取实际播放音轨，滚动保留最多24秒PCM，串行送给 FunASR。识别文字与完整回答的结尾比较，默认匹配度70%；15字以上（含15字）比较末尾10字，短回答比较全文，并单独确认最后3字（不足3字则整句）。同音字按音节匹配，标点与数字读法归一。界面显示实际识别文字、匹配度和末尾确认状态，可在槽位空闲时调整匹配度。

仅当前会话、槽位、采集的结果有效；全部PCM须已发送完成，采集时刻须晚于或等于发送完成和最近发声。结尾确认后不再固定等待静音；识别失败、音视频断流或60秒超时保留人工确认。发送完成时会补一次新结尾识别，不清空已采集音频，避免只有早期识别结果而无法结束。歌曲继续以原音频 ended 结束。
