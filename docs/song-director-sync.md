# 歌曲导播漏词与同步检测

2026-10-22 排查会话 `1010810347315023872`：序号 109 的歌词为第 8 段，时间为 38.940～42.420 秒；下一段从 99.900 秒才开始。原始 `raw.srt` 与校正后的 `corrected.srt` 都缺少中间 57.480 秒，因此调度器没有后续到期指令。19:12:33 的信令为主动挂断 `user_end`，此前未记录服务端指令错误或强制挂断。这次停发的直接原因是时间轴漏识别。

歌曲识别关闭 `hallucination_silence_threshold=1.0` 的语音幻觉跳过策略，并采用 Whisper 的联合静音判定：高无语音概率且低平均置信度才丢弃；不再仅凭低置信度删除演唱片段。中文歌曲明确指定中文，避免前奏影响语言识别。普通语音的过滤保持原有逻辑。参考 [faster-whisper 参数与实现](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/transcribe.py)。

同一首本机原音频使用 small / CUDA / float16 实测：51 段恢复到 71 段，约 5.1 秒完成推理，43.120 秒起的“后来天空变得很淡”及首段副歌均重新出现。识别仍可能有错字、切句偏差和间奏幻觉，应试听并校正，不能把段数增加视为全曲逐字正确。

## 更新已有歌曲

重启应用以加载新的后端与 Whisper 工作脚本。先完成或跳过队列内的旧歌曲任务，再到“唱歌模块 → 编辑 → 重新识别并校正”，检查时间轴后重新加入队列。已有字幕不会因代码更新自动改写。仅点击“校正歌词”会保留旧时间戳与段数，无法补齐漏识别的段落。

歌曲卡片会显示超过 10 秒的内部时间轴空档；它既可能是间奏，也可能是漏词，需要试听确认。播放时 TTS 面板显示原歌曲进度、已发送段数、下一段发送时刻与倒计时。

## 如何理解同步日志

- **已写入连接**：实际 WebSocket 写入成功；IPC 返回也等待这一结果，不再只表示入队成功。它不是 Vidu 生成回执。
- **检测到下行发声**：健康的 RTC 音轨在至少 350 毫秒静音后出现新的语音活动。日志记录从客户端提交到发声的耗时，以及发声时原歌曲进度相对歌词起点的偏差。正偏差表示较晚，可作为增大该段提前量的参考。
- **无法独立测量**：发送时上一句仍在发声、静音不足或音频检测不可用。不会把连续声音强行当作本句生成确认。
- **尚未确认生成**：5 秒内没有可对应的新发声，或下一句到期、歌曲停止前仍无对应证据。没有自动重发，以免重复和积压。
- **已过期跳过**：窗口恢复或异步写入返回后，重新读取本地音频时钟，过期歌词不补发。

歌词通过 `type=99 / text_msg` 发送，保留原有歌词 `msg_id`；歌曲观察记录使用相同歌词 `msg_id` 关联，保存在现有 `tts-log.jsonl`，便于回看。Vidu `type=103` 有对应 `msg_id` 时记录拒绝原因；当前歌曲被拒绝时停止本地音乐。连接写入有 3 秒超时，歌词 IPC 确认有 4 秒超时，播放器另有 5 秒停滞保护。

下行语音没有逐条 `msg_id` 标记，检测到声音只能推测与待测歌词的对应关系；后台动作、旧输出和 RTC 音视频缓冲均会影响测量。此功能不检测嘴部视频像素，也未验证远端音频与视频的播放偏差，不应标为“已生成口型”或自动校准。

## 原唱口型的限制

提前量可以调整开始时间，不能让普通 TTS 的朗读音素时长、停顿、拖音自动变成原唱节奏。若要求逐字和原唱匹配，需要以原唱人声驱动数字人，并使用同一媒体时间轴播放音视频。Vidu 官方将自带音频驱动实时画面的能力列为 Avatar 组件版，见 [功能列表](https://platform.vidu.cn/docs/function-list)。本次未切换服务版本或创建付费生成任务，未执行 Vidu 实时画面的同步验收。

## 验证

`npm test` 覆盖长空档提示、音频时钟、异步写入后过期歌词跳过、发送卡住停止、健康静音后的发声测量、连续发声不误标延迟、服务端拒绝以及 OBS 日志关联。`npm run build`、`cargo test --manifest-path src-tauri/Cargo.toml` 检查前后端。

实际本地模型测试可设置 `WHISPER_TEST_SONG` 为本次歌曲的本地路径、`WHISPER_TEST_PCM` 为中文语音测试 PCM，并将 CUDA DLL 目录加入当前测试进程 PATH，运行：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml whisper::tests::local_ -- --ignored --nocapture
```

两项实际音频测试分别检查歌曲 42～100 秒间的主歌与副歌恢复，以及普通中文语音识别和纯静音不输出文字。
